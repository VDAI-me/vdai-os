# Стратегия / Strategy

## RU

Ближайшая цель: третий участник с другим языком проходит понятный вход и делает один принятый вклад в существующий проект.

1. Один вход: https://os.vdai.me/, RU/EN и один главный шаг участия. GitHub — код и документы, не регистрация.
2. Одна задача: владелец, участник, ожидаемый результат и критерий проверки. Начать с английского входа и одного улучшения.
3. Общая работа: адресное приглашение, одна задача на разных компьютерах, комментарий, результат и решение владельца. Проверить запрет чужого проекта и отзыв доступа.
4. Агентский вклад: разрешённый контекст → существующий Bridge → исполнение → доказательство → решение владельца. Не создавать вторую очередь или параллельную CRM.
5. Повторяемость: следующая задача и участник. Измерять время до первого полезного вклада, уточнения и долю принятых результатов.

Публикация сайта, код, тест и ответ AI не доказывают рабочий доступ или приёмку участником. Общий login/invite и установка внешнего участника не подтверждены. Частные данные, расходы, публикация и внешняя отправка требуют точного разрешения владельца.

## EN

Next-stage goal: a third participant using another language follows a clear entry path and delivers one accepted contribution to an existing project.

1. One entry: https://os.vdai.me/, RU/EN and one primary participation action. GitHub holds code and documents; it is not registration.
2. One task: owner, contributor, expected outcome and review criteria. Start with the English entry and one improvement.
3. Shared work: a personal invitation, the same task on different computers, a comment, a result and the owner's decision. Deny unrelated projects and test revocation.
4. Agent contribution: approved context → existing Bridge → execution → evidence → owner decision. No second queue or parallel CRM.
5. Repeatability: another task and participant. Measure time to first useful contribution, clarifications and accepted results.

A published website, source, test or AI response does not establish working access or participant acceptance. Shared login/invitations and external-participant installation are not verified yet. Private data, spending, publication and external sends require specific owner approval.
