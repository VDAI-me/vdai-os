# Как присоединиться / How to join

**Одна ссылка / One link: [os.vdai.me](https://os.vdai.me/)**

## RU

1. Откройте страницу, при необходимости переключите RU/EN.
2. Нажмите «Присоединиться к VDAI», затем «Написать Дмитрию в Telegram». Email доступен там же как запасной вариант.
3. Расскажите о навыках, желаемом вкладе или обучении и доступном времени. Например: «Могу проверить английскую страницу и предложить одно улучшение на этой неделе».
4. Согласуйте первую задачу, результат и место обсуждения.
5. Передайте воспроизводимый пример и получите решение владельца.

Docker, GitHub-аккаунт и установка OS для первого контакта не нужны. Обращение не создаёт аккаунт. Рабочий механизм приглашения в общую OS ещё не подтверждён. Club не даёт доступа ко всем проектам.

Для изменения кода сначала согласуйте задачу, затем предложите изменение через issue или pull request в этом репозитории. Создание issue само по себе не означает приёмку задачи.

## EN

1. Open the entry page and switch to EN.
2. Select “Join VDAI”, then “Contact Dmitrii on Telegram”. Email is available on the same page as a fallback.
3. Describe your skills, intended contribution or learning goal and time available. Example: “I can test the English page and suggest one improvement this week.”
4. Agree on one task, expected result and where to discuss it.
5. Submit a reproducible example and receive the owner's decision.

No Docker, GitHub account or OS installation is needed for first contact. Contact does not create an account. A working shared-OS invitation mechanism is not verified yet. Club participation does not grant access to every project.

For code changes, agree on the task first, then propose an issue or pull request in this repository. Creating an issue does not establish owner acceptance.
