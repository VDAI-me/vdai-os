WINDOWS · БЕЗОПАСНЫЙ PREFLIGHT

Сначала проверка.
Потом запуск.

Установка для разработчиков; готового пакета нет. Участие можно обсудить без установки программы.

Как присоединиться
Проверить компьютер

В PowerShell из клонированного репозитория: .\scripts\windows-preflight.ps1. Установка зависимостей выполняется отдельно и только с явным -Install.

Проверить bootstrap

.\scripts\windows-bootstrap.ps1 создаёт локальные секреты, но ничего не запускает. Для старта: .\scripts\windows-bootstrap.ps1 -Start.

Граница доказательства

Работа localhost не означает общий доступ. Не отправляйте никому .env, API key или пароль.
