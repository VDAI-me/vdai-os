Как присоединиться
Что понадобится

macOS, Docker Desktop, Git и 8 GB RAM. Готового релиза для скачивания пока нет. Репозиторий предназначен разработчикам; успешная установка из исходников здесь независимо не подтверждена.

Проверка и запуск

git clone https://github.com/VDAI-me/vdai-os.git
cd vdai-os
./scripts/local-preflight.sh
./scripts/bootstrap.sh

После локальной проверки откройте http://localhost:3000. Это доказывает только работу на вашем Mac.

Что должно получиться

Открыт синтетический проект, создан запрос помощи или критики, а runtime/install-proof.json не содержит секретов.
