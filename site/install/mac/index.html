Один мастер запуска.

Сначала подключите формат работы AI. Затем установите свою локальную ОС.

Скачать ОС с мастером запуска
1

Распакуйте ZIP

Оставьте все файлы в одной папке. Прочитайте START-HERE.md.

2

Запустите Start VDAI.command

Мастер проверит зависимости, запросит согласие и покажет ход установки. Не закрывайте терминал.

Перед запуском

Нужны установленный и запущенный Docker Desktop, Node 24.5+ (ниже 25) и pnpm 11.19+. Windows также нужен Git Bash. Если инструментов нет, мастер остановится и назовёт недостающее.

Docker Desktop · Node 24 · Git для Windows
Что будет дальше?

После запуска откройте http://localhost:3000 и создайте локального администратора. Вернитесь в терминал и нажмите Enter. Проверьте страницу OAuth для своей локальной ОС. Мастер применит VDAI; проверьте, что видны проекты и задачи.

Если защита ОС блокирует скрипт

Комплект исходников не подписан. Не отключайте защиту целиком. Прочитайте скрипт, затем запустите bash scripts/start-guided.sh из папки комплекта в Terminal / Git Bash.

Остановить или повторить

docker compose down останавливает ОС и сохраняет данные. Повторный запуск использует ту же папку. Не добавляйте --volumes, если не хотите удалить базу.

Два шага входа не отменяют установку зависимостей, создание администратора и OAuth. Первый запуск на вашем компьютере ещё требует проверки. Локальная ОС не подключает к общей команде.
