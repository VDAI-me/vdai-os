Check your computer

In PowerShell, from a cloned source repository: .\scripts\windows-preflight.ps1. Dependency installation is a separate step and requires an explicit -Install.

Prepare the local instance

.\scripts\windows-bootstrap.ps1 creates local credentials without starting the instance. To start: .\scripts\windows-bootstrap.ps1 -Start.

What this verifies

Running localhost does not establish shared access. Never share .env, an API key or a password.
