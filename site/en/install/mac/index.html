Before you start

Docker Desktop must be installed and running. You need Node 24.5+ (below 25) and pnpm 11.19+. Windows also needs Git Bash. Without these tools the launcher stops and names what to install.

Docker Desktop · Node 24 · Git for Windows
What happens next?

After startup, open http://localhost:3000 and create your local administrator. Return to the terminal and press Enter. Review the OAuth page for your local workspace. The launcher applies VDAI. Check that Projects and Tasks are visible.

If the downloaded script is blocked

This source bundle is not signed. Do not disable security globally. Read the script, then run bash scripts/start-guided.sh from the extracted folder in Terminal / Git Bash.

Stop or retry safely

docker compose down stops the local OS while keeping data. Rerun the same launcher to retry. Do not add --volumes unless you intend to delete your database.

Two entry steps do not remove prerequisite installation, administrator creation or OAuth. First launch on your machine still needs verification. Local installation does not connect you to the shared team.
