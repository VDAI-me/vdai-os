What you need

macOS, Docker Desktop, Git and 8 GB RAM. No downloadable release exists yet. The public repository is for developers; a successful local setup has not been independently verified here.

Check and start

git clone https://github.com/VDAI-me/vdai-os.git
cd vdai-os
./scripts/local-preflight.sh
./scripts/bootstrap.sh

After the local checks, open http://localhost:3000. This verifies operation on your Mac only.

Expected result

Open a synthetic project, create a help or review request, and check that runtime/install-proof.json contains no secrets.
